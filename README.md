# Purpose
This is an example project completed as a job application assessment. All identifying information about the assessment questions have been removed so that this may only serve as an example of my work.

## Topic
This project focuses on the comparison of two sets of loan data. The original assessment only provided a few possible lines of data, so I created two csv files of pseudodata in the same format in order to demonstrate possible outputs of the plots and tables.

## Readability
Due to the difficulty of tracking jupyter notebooks in github, a pdf of the jupyter notebook printout has also been provided. While it does cut off some of the code for long lines, it shows graphs and the reasoning of any decisions made very well.
